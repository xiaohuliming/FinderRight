# 1.2.0 预览版验证记录

验证日期：2026-09-28。

## 已验证

- 使用上游实际服务代码和两个临时文件复现连续剪切删除上一批文件的问题。
- Swift Package 17 项测试通过。覆盖连续剪切、取消、队列持久化、部分失败保留、同名保护、旧暂存恢复、文件夹递归移动拒绝、重命名预验证和路径验证。
- ZIP 和 TAR.GZ 创建与解压的实际往返通过，原目录中的同名文件内容保持不变。
- 构造真实 TAR 路径穿越与符号链接逃逸压缩包，确认操作失败且外部文件未被覆盖。
- PNG、JPEG、HEIC、TIFF 编码通过，原图不变。缩放比例、不放大、JPEG 白底和动画拒绝测试通过。
- 图片转 PDF、PDF 与图片合并的输出页数通过。
- Xcode Debug 构建及 arm64、x86_64 双架构 Release 构建通过。
- 本地 ad-hoc 签名通过 `codesign --verify --deep --strict`。
- 实际设置窗口能切换分区，添加模板后能重新读取所保存的名称、扩展名和内容。
- 实际 iCloud 目录的 Finder 右键“服务”已出现新增入口。通过该入口剪切临时文件后，队列正确记录路径，原文件仍在原位置。

- Intel 真机运行与 macOS 13 最低版本运行尚未验证，当前仅完成相应架构编译。
- 登录启动、辅助功能授权后的隐藏文件切换、各种外接盘和第三方云盘仍需逐项实机验证。
- 设置窗口的辅助功能树验证通过，但屏幕捕获服务不稳定，尚未完成完整的浅色与深色视觉验收。

这里记录的是当前证据，不将编译通过、扩展注册或入口可见等同于全部功能实机验收。
